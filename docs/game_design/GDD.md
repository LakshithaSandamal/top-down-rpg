# Game Design Document

# Title: Echoes of the Verdant Realm

## Overview
A mobile top-down action RPG where players restore a corrupted living world using exploration, combat, crafting and upgrades.

## Genre
2D top-down action adventure RPG.

## Audience
Mobile players who enjoy casual exploration with deeper progression.

## Core Loop
Explore zones -> defeat enemies -> collect resources -> upgrade abilities -> unlock new areas.

## Player Fantasy
Become the guardian who heals a damaged world.

## Progression
Character levels, equipment upgrades, abilities, world restoration milestones.

## Difficulty
Early zones teach mechanics. Later zones introduce enemy combinations and boss mechanics.

## Systems

### Flow
Loading Screen -> Main Menu -> World Selection -> Gameplay -> Inventory -> Upgrade -> Next Challenge.

### Controls
Mobile touch movement, action buttons, contextual interactions.

### World
Connected handcrafted regions with increasing challenges.

### Enemies
Different behaviors, strengths, weaknesses and attack patterns.

### Bosses
Large encounters with phases and unique mechanics.

### Items
Weapons, materials, consumables and quest items.

### Inventory
Grid-based storage with categories and upgrades.

### Economy
Resources earned through exploration and combat.

### Save
Local player profile with versioned save data.

### UI
Loading, menu, HUD, inventory, upgrade, settings and world screens.

## Monetization
Optional cosmetic purchases and rewarded ads without harming gameplay.

## Expansion
New regions, enemies, quests, abilities and events.
