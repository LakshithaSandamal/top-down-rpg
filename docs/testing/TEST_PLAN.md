# Test Plan

## Gameplay
Verify movement, combat, inventory and progression.

## UI
Test every screen flow and touch interaction.

## Performance
Measure FPS, memory usage and loading times.

## Android
Test builds, touch controls, battery and device compatibility.

## Bug Format
Title, steps, expected result, actual result, severity.

## Release Checklist
Stable build, no critical bugs, optimized assets, tested devices.
