# Vector Art Style Guide

## Rule
No PNG sprite sheets. All visuals must be scalable vector assets.

## Style
Clean shapes, readable silhouettes, consistent outlines.

## Characters
Idle: 6 frames.
Walk: 8 frames.
Attack: 6-10 frames.
Damage: 3-5 frames.
Death: 6-10 frames.

## Enemies
Same animation requirements with unique silhouettes.

## Environment
Modular SVG terrain, props, structures and effects.

## Objects
Simple recognizable shapes with consistent stroke language.

## UI
Vector icons, scalable panels and buttons.

## Palette
Limited harmonious colors with clear gameplay contrast.

## Naming
category_object_variant_version.

## Export
Optimized SVG resources suitable for Android.
