# PROJECT RULES

## Coding
- Godot 4.7 and GDScript only.
- Use modular systems and typed scripts.

## Naming
- Scenes use PascalCase.
- Scripts and folders use snake_case.

## Art Rule
All game visuals must use vector assets only. SVG, Godot vector resources, and procedural shapes are allowed. Raster sprite sheets are forbidden.

## Git
Use small focused commits. Document architecture changes.

## AI Development
Inspect existing code before changes. Work on one system at a time. Follow this file.

## Testing
Every feature requires gameplay, UI, and performance testing before release.
