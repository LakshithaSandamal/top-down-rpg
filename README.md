# Top Down RPG - Production Foundation

Godot 4.7 mobile 2D top-down RPG foundation.

## Current Phase

This repository currently contains the professional production documentation pipeline. Gameplay implementation has intentionally not started.

## Development Rules

- Godot 4.7
- GDScript
- Android target
- Vector-only artwork pipeline
- AI-assisted development workflow
